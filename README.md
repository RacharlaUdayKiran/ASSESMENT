This is a full-stack application that lets users look up domain WHOIS information using the WhoisXML API.
Here features are: React frontend , Express backend, Fetches domain data via WhoisXML API, Runs on localhost:500
Technologies are: React, Node.js, Axios, WhoisXML API
Installisation: Clone the repository, Git clone https://github.com/RacharlaUdayKiran/ASSESMENT.git
API KEY SETUP : Add a WhoisXML API key in the backend code.
Running the App : Backend is server side.
Running the App: Frontend is Clint side.
